# KiteKeep launcher V1 product boundary

V1 establishes the secure child launcher platform before educational games are developed.

Core capabilities:

- custom Android Home launcher
- child-facing app library
- parent PIN gate
- parent dashboard
- Device Owner / DPC provisioning support
- Lock Task based child lockdown
- parent-managed approved application list
- safe launch of approved external apps
- return-to-child-mode controls
- reboot and recovery behavior
- local-only settings and child profile foundation
- automated and adversarial testing
- signed release APK and provisioning instructions

Educational game mechanics and content are intentionally outside this development sequence. They will receive a separate staged development system after the launcher platform is stable.
