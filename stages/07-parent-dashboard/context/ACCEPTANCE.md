# Acceptance criteria

- [ ] Parent dashboard is reachable only after authorization.
- [ ] Approved apps can be managed from Parent Mode.
- [ ] Temporary unrestricted access has an explicit return-to-child control.
- [ ] Phone/tablet and portrait/landscape layouts are usable.
- [ ] Accessibility basics are covered by UI tests or evidence.

## Required validation commands

- `cd src; .\gradlew.bat test lint`
